### <b style="font-size:18px">FlexGate - 高性能 API 网关（个人开源项目）</b> ｜ `2025.03-至今`

**项目描述**

FlexGate 是一个基于 Go 语言开发的高性能轻量级 API 网关，专为现代云原生架构设计。已在 GitHub 开源，提供反向代理、动态路径重写、限流、请求追踪等核心功能。

**运用技术**

- Go 1.23+ / Gin Web 框架
- 令牌桶限流算法（Token Bucket）
- 责任链模式的中间件架构
- Reverse Proxy 反向代理
- YAML 配置驱动

**工作描述**

1. **独立完成项目架构设计与开发**，从需求分析到源码实现全程主导。
2. **实现反向代理核心功能**：使用 `httputil.ReverseProxy` 实现请求转发，支持动态路径重写（`strip_prefix`）。
3. **实现令牌桶限流器**：支持路由级别限流配置，允许瞬时并发冲刺。
4. **设计中间件链**：实现 Recovery（Panic 恢复）、Logger（结构化日志）、RequestID（请求追踪）、RateLimiter（限流）四大核心中间件。
5. **解决 Gin 路由匹配问题**：同时支持 `/api/users` 和 `/api/users/` 两种路径格式，禁用自动重定向。
6. **实现请求追踪**：每个请求生成唯一 16 字节十六进制 ID，支持分布式链路追踪。
7. **完善工程化文档**：编写双语 README、架构图、快速开始指南。

**项目亮点**

- 🔄 代理转发延迟 < 1ms，支持 10,000+ QPS
- 🛡️ 统一错误响应格式，返回 JSON 格式错误信息
- 🔍 支持 `X-Request-ID` 请求追踪，便于分布式日志分析
- 🚦 基于令牌桶算法，支持路由级别限流配置
- 📚 完整双语文档，开源项目规范
